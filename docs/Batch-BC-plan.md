## 2. 三站固定流程

| 站点 | 既定问题与任务 | 完成反馈 |
| --- | --- | --- |
| 上海老饭店 | 说明不吃辣 → 主动询问推荐 → 在清蒸鱼、白斩鸡、辣味豆腐中选择 → 核对实际菜品。推荐和用户选择分别记录；辣菜不能满足本次不辣任务 | 保存后呈上所选菜品，回顾偏好、推荐与选菜表达 |
| 上海梨膏糖商店 | 听店员介绍一种口味（玫瑰/桂花/薄荷）→ 选择并练习对应口味 → 表达两包 → 核对实际商品、口味与数量 | 保存后包装交付；回顾听辨材料与购买表达 |
| 湖心亭茶楼 | 评价这杯茶 → 向主人道谢 | 用户明确继续并保存后自然致意；无订单核对题，提供本站与路线回顾 |

最新固定题要求覆盖旧草案中的任意顺序、自动推进和临时追问。各题可以重试或修改，不由模型额外生成对话问题。茶楼的“继续”用于提交当前结果，不增加一次“对不对”的确认练习。

## 3. 共用交互与内容

- 先选择想表达的目标，再显示该句并录音。停止录音后自动识别，展示原转写和是否符合本题，用户点击继续才应用结果。首次需尝试 Speak；失败一次或技术不可用后可辅助继续，不能将辅助记作语音正确。
- 不恢复 Type、前端 phrase book 按钮或反复说明实现限制的辅助提示。单站完成后开放表达 Review。
- 汉字与拉丁注音对齐，隐藏声调数字，注音默认显示且可关闭；意思和操作按中文/英文切换。常速 1× 与保音高慢放 0.75×复用本地音频。
- 内容和 TTS 允许以明确的待审稿接入，供用户逐句审阅；本批开发完成不伪造语言、注音或声音听审批准。
- 梨膏糖的目标在同一尝试内固定。播放失败不视为已听；字幕、注音、翻译和目标高亮默认不提前出现。明确打开文字帮助可以继续，记录帮助事实。每种口味的商品展示保持同等显著。
- 三站独立室内构图、角色、物件和交付动作，沿用地图色彩。菜单菜品、糖罐与茶具以可编辑 SVG/组件制作，正文和操作不烘焙在图片内。
