| 明确继续 | 正确后点击下一步才应用本题目标；最后核对同样先显示结果，点击确认并完成且保存成功才完成。评估本身不播放下一题、不开放 Review |

| 宽容核对 | 有限的确定性目标核对接受合理省略及数量题“两分”等同音误写；原文始终保留。否定、相反方式、冲突数量、只/笼与分钟/分数不被当成份数通过 |
| 版本与声音 | 新会话采用 `batch-a-r3.2026-10-17.v1` / `nanxiang-rules.v3`；R1/R2 保留原内容与规则。20 条教材原文/注音不变，R3 复用 R2 声音，13 条用于当前流程、7 条标记历史分支 |

核对结果只表示是否符合本题表达，不是每字发音、声调或掌握程度的评分。当前流程不调用自由对话模型。

## 3. 浏览器实测

Chrome 使用隔离的 `localhost:5174` 前端、8001 后端与测试数据库，真实 ASR/TTS/LLM 全部关闭。通过测试夹具向实际后端保存**合成识别结果**，再从实际页面操作；这验证结果展示与推进链路，不代表经过真人麦克风或真实识别供应商。

| 场景 | 实测结果 |
| --- | --- |
| 正确与原文 | 目标两份，合成转写“两分。”显示正确，仍在数量题、订单数量未提交；刷新保留原文和结果，点击下一步才进入方式题并保存两份 |
| 错误与辅助 | 目标两份，合成转写“七份。”显示不正确，停在数量题且不追问单位；点击用所选答案继续后保存两份，没有采纳七份 |
| 跨页面恢复 | 新标签页重新进入可恢复错误原文和已开放的辅助继续；不依赖原标签页临时状态 |
| 无文字与故障 | 空结果明确显示未获得识别文字；技术失败明确显示暂时无法判定，两者均提供重试与辅助继续 |
