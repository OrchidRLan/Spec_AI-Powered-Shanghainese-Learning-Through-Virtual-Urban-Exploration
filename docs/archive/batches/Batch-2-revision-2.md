## 1. 独立介绍页

主导航新增 About，与 Explore / Review 并列，中文为“探索 / 复习 / 介绍”。默认仍进入探索地图；支持介绍页直达、刷新及前进/返回，不强制首次访问介绍页。

介绍页沿用米白、深绿与现有插画，包含：

1. 品牌开场：Logo、项目名、一句项目介绍，将原地图底部的宣传语移入这里；“开始探索 / 继续探索”进入地图，保留进度。
2. 四个地点：用已有四站插画简要介绍点菜、挑糖、点小笼与品茶的练习内容，不重复展示完成状态。
3. 如何体验：听店员提问 → 选择表达并开口 → 查看结果并点击继续 → 完成后复习；文字与实际固定练习流程一致。
4. 随手帮助：简短介绍注音、标准/慢速和进度保存，吸收原地图底部的三项功能说明。

地图移除底部重复的介绍区；页脚移除 Interface state book / 界面状态册入口。状态样例仅保留作开发验收材料，生产构建不开放该页；不能将技术状态样例直接改名作为介绍内容。

桌面采用有留白的图文布局，手机纵向阅读，三项导航均可访问。介绍页不产生任务完成或学习统计。

## 2. Settings 与统一开关

Settings 保留界面语言、显示注音、减少动态效果和店员声音；移除 Start a new journey / 开始新的探索按钮及普通用户的重开入口，保留各站 Try it again。

原版本兼容提示如必须显式新建当前版本会话，仍可保留专门恢复流程；不得自动清空旧会话。底层新会话能力不删除，普通设置页不再承担进度重开。

所有设置和四站的注音开关统一成一套组件：深绿开启、灰绿关闭、白色圆点始终在胶囊轨道内；建议轨道 46 × 26 px，圆点 20 px、内缩 3 px，独立至少 44 px 点击区域。文字间距 10–12 px、垂直居中。清除粗白边伪造轨道和两次右移的叠加样式。

保留键盘操作、可访问名称、明确开关状态、保存中的禁用状态。设置页与题目中的注音保持同一偏好，四站共用；减少动态设置也作用于开关过渡。

## 3. 桌面 Logo 间距

保留已选园亭图形、原字形与配色，增加图标和字标之间的内部间距，页面显示约 12–16 px，以实际视觉校准。优先以现有素材分区排版保留原像素；如需要整理素材，也不重新设计品牌。

图标与文字各自尺寸基本保持，检查组合宽度与三项导航、语言/设置工具的关系；手机紧凑版继续适配。

## 4. 验收与交接

检查双语介绍页、默认地图、三项导航、直达/刷新/前进返回、介绍 CTA 保留进度、生产状态册入口限制、Settings 无普通重开入口、四站与设置开关的同步和键盘状态。实际检查桌面、390 px 与 320 px 手机视口及关键开关位置。

按改动执行前端回归、类型与开发构建，更新验收和开发进度后提交推送。无新增真实语音调用、部署、教学审核批准或用户数据重置。
