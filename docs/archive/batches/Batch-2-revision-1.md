## 1. 完成后的店员结束语

老饭店、梨膏糖、湖心亭当前会显示结束句，但共用播放逻辑跳过已完成状态；音频文件已存在。修复三站，并回归南翔：用户明确点击完成、保存成功后，自动播放当前站点的结束句一次，播放期间显示说话状态，结束后保留完成姿态。

- 尊重“店员声音”开关，保留手动重听；不重新生成 TTS。
- 刷新或重新打开已完成站点时不自动重播，离开页面停止声音。
- 保存失败不播放完成语；重试、重复响应、查询恢复不得重复播报或误宣告完成。
- 声音播放不锁住 Review、返回地图或再练入口，不增加确认题。

## 2. Review 总览与单站详情

Review 总览只展示四个地点的插画、名称、真实状态和入口。移除语音次数、帮助次数、大段完成提示、自动展开的示例和重复站点切换栏。0/4 时也能访问总览；已完成站点显示 Review，未开始或进行中的站点提供 Start / Continue，暂离状态仍真实显示。

点击某站 Review 后进入该站表达详情，提供返回总览入口。未完成的站点不开放表达复习；重练保留已有成功记录和复习资格。从站点完成页点击 Review 直接进入本站详情。浏览器前进/返回、刷新和直达链接应保持所选页面，非法或未解锁的详情回到总览，不清空会话。

每条表达显示上海话汉字、字音对齐注音及当前语言释义，并独立提供 Normal / Slow 两个按钮。点击立即按 1× / 0.75× 保音高播放同一份本地声音；任何时候只播放一条，播放另一句或离开详情会停止上一条。取消统一语速控制栏，注音沿用设置中的显示偏好。复习播放不修改任务页面的语速偏好。

## 3. 园亭对话 Logo 接入

采用用户在 [设计项目 Logo 候选](thread://01a14b79-7543-7372-a9a9-2313ecd3a88f?hostId=local) 中选定的第一款“园亭对话”，保留园亭、桥、水纹、树、对话轮廓与深青绿/赭红配色。已提供纯图标、文字在下方、文字在右侧三种版本。

- 桌面页头采用左右组合；手机使用紧凑图标与品牌呈现，避免挤压导航及语言设置。
- 接入浏览器图标；小尺寸检查轮廓与内部细节，按需要简化小图标，不改变主 Logo。
- 将带底色的原 PNG 整理为透明底网页素材，控制留白、比例和清晰度；原图与生成/处理来源留在设计交接中。
- 上下组合保留为介绍/封面资产，不为使用该版本额外增加页面。
- 品牌名称为“沪语漫游 / A little Shanghai”，保留回地图行为和可访问名称；不改变四站场景或页面主色。
