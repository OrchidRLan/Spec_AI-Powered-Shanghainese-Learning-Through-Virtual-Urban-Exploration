## 2. 自动化与构建

- `npm run check`：类型检查、22 项内容回归、8 项前端教材释义回归、99 项后端检查，以及 20 条审阅音频完整性检查。测试不调用真实模型。
- `npm run build`：开发预览构建通过，允许明确待审内容。`build` 保持纯 Node 流程。
- `scripts/speech-review.py check`：20 个文件、29,840ms，SHA、WAV、生成参数、原文与版本一致，正式批准快照未变，网络调用为 0。
- `scripts/speech-review.py plan`：重复运行需要 0 个新请求、估计新增费用为 0，防止每次播放或重复制作再收费。
- 正式内容检查依然阻止发布：332 项批准/参考音频/正式素材等条件未满足。主内容包 28 个正式常/慢速条目仍 pending；审阅素材使用独立清单，不伪造审批。

用户另行明确授权后，用 E08 合成教学音频补做了 **1 次真实 ASR**，没有追加 LLM/TTS。返回原转写「我要两份小笼馒头。」，接口耗时 1699ms；随后在隔离会话提交 voice 回合，结果为商品 `xiaolongbao`、数量 `2`、单位 `serving`、外带 `null`，进入 `NX-N03` 继续询问方式，没有自动完成。原转写和语音来源保留。这是合成样音的接口技术回归，不是浏览器麦克风或真人语音验证；未模拟 `recording_started`，语音尝试数保持 0。ASR 返回未提供计费 usage，因此不编造账单或费用。
