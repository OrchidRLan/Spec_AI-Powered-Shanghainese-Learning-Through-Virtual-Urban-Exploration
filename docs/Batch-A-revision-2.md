# 批次 A 修订 2：开口练习、自由点单与完成后复习

确认日期：2026-10-17。用户要求先将本修订落盘，再开始修改代码。本文为已确认需求基线，实施与验证状态单独记录，不把计划视作完成。

## 1. 范围与覆盖关系

在批次 A 修订 1 的实际应用上修改南翔体验，不开展其他三站业务、生产部署或研究实验。本修订覆盖旧稿中的固定两份外带、默认可直接按钮答题、手动提交录音与转写、词组整体对齐、任务中 Phrase book 入口和暂缓慢速等安排。

南翔目标为完成一笔有效小笼订单：用户决定数量与堂吃/外带，不再要求两份或固定外带。数量沿用 1–20 份的有效范围，界面先提供一、二、三份的便捷练习选项；语音可表达其他有效数量。商品、数量、单位和用餐方式明确后展示实际订单摘要，用户明确确认并保存成功才完成。未知字段不由示例或预选答案补齐。

## 2. 注音与声音

- 所有学习界面隐藏罗马注音的声调数字，暂不增加声调解释。内容源保留完整注音和依据，不伪造新的语言审核。
- 每个汉字与对应音节上下对齐，词组之间留间距；汉字与音节作为同一单元换行。不能对应的内容保留合理分组，不强行错配。当前语言释义单独展示。
- 注音默认开启且可隐藏；在 Speak、问题、选项和完成后 Review 中保持一致。
- 提供标准 1×、慢速约 0.75×，默认标准，复用已保存声音并保留音高。该慢速是播放减速，不冒充重新录制的教学慢读；若听感不佳再评估独立慢速素材。
- 播放互斥，开始录音停止示范音频；未改变的语句复用已生成样音，改稿不得播放旧句或错误数量/方式。新增声音仍沿用待审状态，技术验证不代替听审。

## 3. Speak 与按钮回答

每道题采用以下流程：当前问题 → 选择“我想说什么” → 显示对应汉字、注音、意思和试听 → 主动开始/结束录音 → 自动识别 → 自动提交原始转写 → 反馈和下一题。

- 前置选择仅选择练习内容，例如一份/两份/三份，不提交订单，不算已经回答，也不能代替真实录音证据。对应句子跟随所选内容，未选时不展示固定答案的录音卡。
- 每道题默认先 Speak。首次识别为空、无法理解或本轮语音回答无法接受后，开放“用选项回答”，同时保留“再说一次”。同一道题保持解锁，进入下一题重置；刷新不应把同一道题已解锁的回退丢掉。
- 麦克风不可用、权限拒绝或语音服务故障时可以直接使用按钮回答，不要求反复尝试，不把技术故障称为发音错误。取消录音不算识别失败。
- 去掉“提交录音识别”“使用这句话”的额外点击。原始转写可作为简短反馈展示，不再要求通过教材原句匹配后手动确认。保留最后一轮订单摘要与明确确认；自动提交普通回答不能跳过该轮。
- 本次保留明确的录音结束按钮，不增加静音自动停止，避免思考停顿被截断。不得自动开启麦克风。
- 切题、切换练习内容、取消、离开及新会话使旧录音/迟到结果失效；重复请求不重复推进。录音区域移除长期存储说明文案，实际资源处理不因去掉文案而改变。

## 4. 更宽容、准确的反馈

放宽合理省略、口头语、常用同义表达和当前问题明确提供的上下文。例如数量问题中的“两份”“我要两份”都可理解。不要求转写与教材逐字相同；教材释义匹配失败不等于语音失败。

仍需准确区分数量、否定、修改、堂吃/外带及份/只等意思。听懂了“一份”即可按一份点单，不再因偏离两份目标失败。预选“两份”而录音说“一份”时，按实际识别意思反馈，不能替换成预选答案。

本修订不实现或宣称逐字发音评分。ASR 错字不等于发音错误，时间戳也不是发音评分；可反馈“这部分没听清”“请再说一次”。真正的沪语逐字发音诊断作为独立能力留待验证。

## 5. 完成后的 Review

- 移除导航、地图和南翔进行中页面的 Phrase book / Pocket phrase book 按钮。
- 当前题必要的语言提示继续直接显示，不需打开合集。
- 南翔订单确认保存、本站完成后，提供明显的 Review / 复习入口，查看本站学过的表达、对齐注音、当前语言意思、标准/慢速试听。
- Review 在本站完成后仍可从完成状态重新进入；未完成或跳过不能靠直接地址绕过。重复练习不抹掉此前已获得的复习资格。
- 完成画面、订单摘要和店员台词以真实数量和堂吃/外带为准，不再固定写两份或一律打包。
