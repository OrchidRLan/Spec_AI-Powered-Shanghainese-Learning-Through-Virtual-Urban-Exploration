# 批次 2 修改 3：实现与验收

日期：2026-10-17。范围以 [修改 3](Batch-2-revision-3.md) 为准，先保存方案再开发。工程检查已完成，待用户体验确认；不代表生产上线或语言材料批准。以下首轮记录保留原始证据，密码和用户名主键的追加调整见末节。

## 已实现

- 品牌欢迎页提供中英登录／注册、密码显示、唯一用户名提示和明显的游客入口。手机先显示表单与游客入口，桌面图文并列。
- 用户名大小写不敏感，数据库唯一约束；密码采用随机盐 scrypt。账号使用可撤销的 HttpOnly Cookie，最长 30 天；注册即登录，第一版不提供密码找回。
- 游客仅在标签页保存访问凭据，刷新和切页保留，正常关闭后新开返回欢迎页；最长 24 小时有效。后续 API 访问或维护命令清理过期游客数据，账号数据不受清理影响。
- 体验中注册承接当前练习，登录已有账号事务合并尝试和历史完成记录，撤销来源凭据。旧匿名数据需明确勾选导入，课程版本不兼容时保留两边记录并提示。
- 导航为 About → Explore → Review；中文为介绍 → 探索 → 复习。登录／注册／新游客默认 About；已登录普通打开也默认 About，有效身份下刷新明确站点继续原页面。
- About 改为「Save your journey / 留住这段漫游」，分别说明账号保存与游客临时保留，游客可直接进入登录。
- 业务请求与退出绑定页面当前会话，防止其他标签切换账号后误写。认证开始隔离旧请求，迟到响应不覆盖新身份；失败保留游客记录。识别、私有糖店声音同样携带身份，声音下载可取消并释放。
- 超过 30 秒的中断 ASR 与历史未完成回合可安全终结，避免永久阻塞迁移；不自动推进任务，保留历史回合原始记录，迟到结果不能再次应用。

## 运行与未覆盖范围

本轮临时浏览器标签、视口设置和测试服务已关闭；用户原有 5173/8000 服务保留。**本次改动包含后端，用户需在原启动终端按 Ctrl+C 后重新运行 `npm run dev`**；前端热更新不能替代后端重启。没有开启新用户服务来占用原端口。

游客正常关页后不再恢复；浏览器的“恢复已关闭标签页／会话恢复”可能恢复标签页凭据，这一平台边界已记录。24 小时是服务端凭据有效期，不是关页即删除承诺；无访问时需要维护任务执行数据清理。

账号系统目前使用本地 SQLite，没有云数据库或公开部署。跨设备恢复需要设备能够访问同一个已部署后端；生产 HTTPS、安全 Cookie、数据库持久化、备份、限流及游客清理计划在部署阶段验证。实体设备、Safari、完整无障碍、真实网络故障与真人语音验证仍按整体路线补齐。

本轮无需新密钥，没有真实 ASR／TTS／LLM 请求或费用。真实语言、注音与声音批准状态保持待审。Git 提交及远端同步以实际历史与主负责人核验为准。

## 追加调整：密码与用户名主键

2026-10-17，按用户后续要求实施：密码由至少 15 字符降为 **8–128 字符**，不要求大小写、数字或符号组合，保留空格；移除中英文界面中的密码找回不可用提示及其空白样式。

原有规范化用户名唯一约束继续生效，并将 `users.username_key` 改为真正的 `NOT NULL PRIMARY KEY COLLATE NOCASE`。注册与登录仍先去除用户名首尾空白并统一大小写；原 `id` 保留 `NOT NULL UNIQUE`，维持令牌和进度的现有引用。启动时事务迁移旧表，保留账号、密码哈希、登录凭据和所有练习记录；复制或外键完整性失败时回滚，不清空数据。
