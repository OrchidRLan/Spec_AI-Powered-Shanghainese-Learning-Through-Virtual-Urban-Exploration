# 当前产品规格

更新：2026-10-17。本文合并批次 A、B+C 与批次 2 修改 1–3 中仍有效的决定，作为当前产品行为入口。用户最新明确要求优先；旧修订用于追溯，不再要求从多份草案拼接现行规则。

功能实现和实际验收是两件事。当前四站、账号与游客体验已有代码交付；语言、声音与完整体验仍有待验收事项。实际证据和下一步见 [开发进度](Development-status.md)，后续部署与验证分工见 [批次 D/E 计划](Batch-DE-plan.md)。

## 1. 产品与范围

- 名称为“沪语漫游 / A little Shanghai”，通过豫园四个日常场景练习上海话。
- 产品是有目标的逐题场景练习，当前不提供无限自由对话、模型临时追问或逐字发音评分。
- 每次语音核对附带宽松版整句内部评分（满分 100、按错误类型扣分、阈值 75），供分析和调参；学习者只看到通过、重试或重录，不展示分数。内容核对仍是必过条件，分数不能放行错误内容。规则见 [宽松评分说明](engineering/Scoring-system.md)。
- 支持中文与英文界面；两种模式保留核心上海话汉字、可隐藏的拉丁注音和教学声音。
- 任务完成、语音尝试和帮助使用分别记录；完成任务不表示发音或语言掌握已获评定。
- 当前范围为完整产品及工程验证；不自动包含参与者招募、学习成效实验或论文研究。

## 2. 入口、导航与设置

- 没有有效账号或当前游客会话时展示品牌欢迎界面：登录、注册与“直接体验”。
- 登录和注册仅填写用户名、密码；提供界面语言切换、密码显示、等待与错误状态。
- 顶部顺序固定为 **About → Explore → Review**，中文为 **介绍 → 探索 → 复习**。
- 新登录、注册或进入游客体验后默认打开 About；已有会话的刷新与有效深链接保留目的页面。
- About 介绍四站、体验步骤及读音、速度、保存帮助，主按钮进入地图，不产生任务完成记录。
- About 使用“Save your journey / 留住这段漫游”：游客需登录才可为下次保存，账号用户可下次登录继续。
- Explore 展示四个可进入的地点及真实进度；Review 总览不要求先完成全部路线。
- Settings 保留界面语言、显示注音、减少动态效果与店员声音；不提供普通“开始新的探索”按钮。
- 各站保留“再练一次”。旧内容版本需要新会话时使用专门兼容流程，不静默清空旧记录。
- 界面状态册仅作开发材料，生产构建不开放；地图页脚不再放介绍或状态册入口。

## 3. 四站既定任务

| 地点 | 固定流程 | 有效完成条件 |
| --- | --- | --- |
| 上海老饭店 | 表达不吃辣 → 主动询问推荐 → 明确选菜 → 完整核对 | 从清蒸鱼、白斩鸡、辣味豆腐中选择满足不辣任务的菜；推荐与选择分别记录，辣菜不能通过 |
| 上海梨膏糖商店 | 听口味介绍 → 听辨并练习对应口味 → 表达两包 → 完整核对 | 对应同一次尝试的玫瑰、桂花或薄荷目标，数量为两包，核对商品、口味与数量 |
| 南翔馒头店 | 商品 → 数量 → 堂吃或外带 → 完整核对 | 小笼订单有效；当前教学选项为一、二、三份，由用户选择方式，不限定两份或外带 |
| 湖心亭茶楼 | 评价这杯茶 → 道谢 | 两题按既定流程提交并保存；不增加订单或“对不对”确认题 |

- 四站可独立进入，地图完成数按有历史成功记录的不同站点聚合；先完成茶楼不代表路线完成。
- 南翔规则保留 1–20 份的有效范围，但当前引导教材只提供一、二、三份，不把未制作数量显示为可练教材。
- 每次只展示当前题及其选项；识别一句自由表达不会跳过其他既定题。
- 所有额外澄清追问均取消。未听清、数量冲突、错口味或不符任务时留在原题，用结果卡说明。
- 编辑返回对应既定题，更新后重新核对；不得继续使用修改前的结果或确认。
- 南翔最后展示商品、实际份数和堂吃／外带，再问“对伐？”，汉字、注音、释义与整句声音一致。
- 当前南翔六种份数／方式组合各有对应确认素材；不完整或未覆盖订单不猜测台词与声音。
- 老饭店与糖店的最后核对也必须包含实际选择；茶楼保持自然道谢收尾。

## 4. 选择、开口与结果停留

1. 用户先选“我想说什么”，再看到对应汉字、注音、当前语言意思与试听。
2. 用户主动开始、结束录音，单次上限 20 秒；不自动打开麦克风，不增加静音自动结束。
3. 停止后自动识别并核对当前目标，无额外“提交录音”或“发送转写”按钮。
4. 显示目标、原始转写和明确结果，停留等待用户操作。
5. 点击“下一步”才保存并前进；最后一步明确完成且保存成功后才显示完成状态。

- 前置选择仅确定练习目标，不提交任务、不证明已经说对，也不能替代真实录音证据。
- 首次需先 Speak；一次识别失败或不符合目标后，可重试或“用所选答案继续”。技术不可用可直接辅助继续。
- 辅助资格随当前题保存，同题换目标仍可用；进入新题、编辑重练或新尝试时重新要求 Speak。
- 辅助仍须符合任务：错误口味或辣菜不能借此完成。辅助继续单独记录，不计为语音正确。
- 成功、失败都展示已取得的原始转写；空转写明确表示未获得文字，服务／设备故障表示暂时无法判定。
- 只核对表达是否符合本题目标，允许合理省略、口头语、停顿与重说、同义表达和有限同音容错；否定、相反意思、冲突数量不得误通过。
- 原转写保持不变；用户选两份但说七份时不通过，也不偷偷写入七份或以教材句替换原话。
- 成功结果不自动切题、播下一题或完成；刷新与返回后仍恢复待继续的结果。
- 移除 Type、自由文字输入与任务内 Phrase book 按钮；旧文字来源记录仍保留可追溯。
- 保留录音计时、处理／保存状态、异常与恢复入口；不重复展示存储说明、机制解释或发音免责声明。

## 5. 梨膏糖听辨边界

- 同一次尝试的口味目标固定，刷新或重复播放不改变目标。
- 未完成介绍播放且未主动打开文字帮助前，不开放对应练习；播放失败不算已听。
- 字幕、注音、翻译与目标高亮不提前出现；三种商品展示同等显著。
- 用户明确打开介绍文字后可以继续，同时记录使用帮助；听辨目标仍须一致。

## 6. 完成与 Review

- 完成后显示真实订单或本站结果，提供 Review、返回探索、再练一次；按钮图标统一在文字左侧。
- 用户明确完成且保存成功后，自动播放本站结束语一次；遵守店员声音设置，可手动重听。
- 保存失败不播放成功结束语；刷新、重开完成页、查询恢复和重复响应不重复自动播放。
- 结束语播放期间角色显示说话状态，之后保留完成姿态；播放不阻止 Review 或离开。
- Review 总览只显示四站插画、名称、状态与入口，不自动展开表达、统计或重复站点切换栏。
- 已完成站点点击 Review 进入本站表达；未完成提供 Start / Continue，暂离状态如实显示。
- 本站完成页的 Review 直达本站详情；详情可返回总览，刷新和前进／返回保留所选页面。
- 未解锁或非法详情链接返回总览，不清空会话；重练保留历史成功和已获得的复习资格。
- 每条表达显示上海话、对齐注音、当前语言意思，独立提供 **Normal 1× / Slow 0.75×** 两个按钮。
- Review 没有统一语速栏，逐句播放不修改任务语速偏好；任何时候仅播放一条，切句或离开停止旧声音。

## 7. 语言、声音与视觉

- 学习文本的汉字与音节上下对齐并一起换行，词组保留间距；不强行错配无法一一对应的分组。
- 界面隐藏声调数字且不增加声调解释；内容源保留原注音、版本和依据。
- 注音默认显示，可在设置或题目中关闭，四站与 Review 使用同一偏好；隐藏不影响汉字和释义。
- 释义、操作与说明随界面语言切换；仅中文模式有默认收起的近似读音，并标注“近似读音，请结合音频”。
- 教学声音提前生成并保存，播放直接复用素材；不在每次播放或对话时重新调用 TTS。
- 标准速为 1×，慢速为同文件 0.75× 保音高播放，不宣称是独立录制的慢读。
- 声音按原句、文字／注音版本、模型／音色、生成记录和文件校验匹配；改稿不能误播旧句。
- 当前上海话、注音与 TTS 是明确待审稿；代码通过、文件可播放或用户通过交互，不等于语言与声音获批。
- 当前适配使用 `qwen3-asr-flash`、`qwen3-tts-flash` 与 Jada；服务经后端适配，不将托管 API 冒称具体开放权重模型。
- 保留园亭对话 Logo、米白与深绿风格；四站建筑轮廓、室内场景、人物及经营物件分别设计。
- 地点卡按站号／状态、建筑、店名、时长／说明、主按钮排列；手机纵向显示，长英文不挤压插画。
- 角色动作与播放、录音、处理和完成状态关联；减少动态时用静态姿态，不影响流程。
- 设置与题目开关共用样式，白色圆点在胶囊内；保留明确名称、键盘操作、状态与足够点击范围。

## 8. 账号、游客与进度承接

- 用户名为 3–24 位英文字母、数字或下划线；裁剪前后空格后校验，显示保留大小写。
- 规范化用户名 `username_key` 是数据库非空主键，大小写不敏感；`Alice` 与 `alice` 不可重复注册。
- 内部账号 ID 保留唯一约束用于既有关系；启动迁移保留旧账号、凭据、密码哈希和进度，不重置数据库。
- 密码为 **8–128 个字符**，允许空格，不强制字符组合、不裁剪密码；采用带随机盐的 scrypt，禁止保存明文。
- 注册成功即登录；用户名占用显示表单错误，错误密码与不存在账号使用相同登录失败提示，并限制重复尝试。
- 账号会话有效期为 30 天，退出撤销凭据；持久账号进度可由同一账号在其他浏览器／设备继续。
- 第一版无邮箱、手机号、第三方登录、个人中心或自助找回；界面不放“尚未提供密码找回”的提示。
- 游客可体验完整四站；凭据限当前标签页会话，切页和正常刷新可恢复，不承诺关闭后或跨设备继续。
- 入口明确提示游客关闭后不保留进度、登录可保存；浏览器恢复关闭标签页可能恢复标签状态，因此不承诺关页即物理删除。
- 游客访问最长有效 24 小时；过期数据在后续 API 访问或清理命令中删除，不承诺无访问时准点执行。
- 游客中途注册承接本次进度；登录已有账号合并当前游客尝试，保留历史成功，不覆盖已完成站点。
- 合并只接受当前持有凭据的游客记录，完成后撤销旧凭据；重复请求不得复制练习或跨账号导入。
- 旧匿名记录不自动删除。持有旧凭据时提供明确保留入口；不同课程版本或冲突无法合并时保留两边记录并解释原因。
- 登录失败或关闭登录浮层可回到当前游客体验；网络结果不明时先恢复身份状态，不擅自丢弃进度。

## 9. 保存、身份与异常恢复

- 业务请求验证会话归属、尝试、步骤、目标、版本与请求标识；规则决定进度，保存成功后才完成。
- 当前回应结果与失败辅助资格可恢复；返回保留已保存进度，明确暂离不计完成。
- 重练创建新尝试，保留旧成功；修改使旧评估和确认失效，迟到、取消和重复请求不能错误推进。
- 保存结果未知时提供查询、重试或取消；不能把客户端超时当作服务端未保存而重复应用。
- 离开、换目标或更换身份停止旧声音／录音并隔离旧请求；未提交录音使用明确离开保护。
- 处理中避免账号切换串写；请求绑定页面当前会话，跨标签身份变化不能把旧练习写入其他账号。
- 身份恢复失败保留可重试入口；过期明确返回欢迎页，不自动创建长期匿名进度。
- 语音密钥仅在服务端；用户录音按私有资源管理，不提交源码、日志或公开教学素材目录。
