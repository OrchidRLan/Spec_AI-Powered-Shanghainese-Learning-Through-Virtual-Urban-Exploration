# 批次 2 修改 3

日期：2026-10-17。用户确认用户名与密码登录／注册、可选游客体验，并要求先落盘再开发。本轮新增账号与临时游客会话；四站任务、语言材料、音频和审核状态沿用现有实现。

## 1. 入口与导航

- 未登录且没有当前游客会话时，自动展示品牌欢迎界面，提供「登录 / 注册」切换、用户名、密码和明显的「直接体验」入口。保留中英文切换、密码显示切换、清晰错误和提交中的状态。
- 采用现有米白、深绿、园亭 Logo 与建筑插画，桌面图文并列；手机优先显示表单和游客入口，介绍放在后面。不新增邮箱、手机号、头像或个人资料表单。
- 已登录者直接进入应用；同一游客体验内刷新和站内切页不重复出现入口。顶部提供账号入口，游客可随时登录／注册保存进度，账号用户可退出。
- 顶部导航固定为 **About → Explore → Review**，中文为 **介绍 → 探索 → 复习**。
- 登录／注册成功默认进入 About；无指定页面的常规打开也默认 About。已有有效会话的明确站点深链接和刷新仍可恢复该页面，避免中断练习。游客点击直接体验进入 About，再由主按钮探索地图。
- 账号切换须先停止音频和录音；存在未提交录音时沿用明确离开保护。处理中的保存不得因账号切换串入另一账号。

## 2. 账号规则

- 登录、注册均仅填写用户名和密码；注册成功直接登录。
- 用户名为 3–24 位英文字母、数字或下划线，大小写不敏感；显示保留用户输入的大小写。服务器规范化并用数据库唯一约束防止重复与并发注册冲突。
- 密码为 15–128 个字符，允许空格与长口令，不强制复杂字符组合；前后空格不自动裁剪。使用专门的加盐密码哈希，不能保存明文或以普通快速摘要替代。
- 错误密码与不存在账号使用同一登录失败提示；注册用户名占用在表单内提示。服务端限制重复尝试，账号会话有过期与退出撤销机制。
- 第一版没有邮箱／手机，也不提供自助密码找回；注册页简短说明请妥善保管密码。新增恢复渠道另行设计，不放入本轮。
- 登录保存的账号进度可在其他浏览器／设备登录继续；本轮不新增第三方登录、社交、排行榜或个人中心。

## 3. 游客与进度

- 游客拥有完整四站体验；进度仅在当前体验中临时保留。站内切页、正常刷新可恢复；正常关闭后重新打开须重新选择入口，不承诺跨设备或长期恢复。
- 游客凭据限定在标签页会话中，不沿用原 30 天匿名 Cookie。浏览器恢复关闭标签页可能恢复原标签页状态，不能承诺关页瞬间删除服务器数据。
- 后端临时数据设最长 24 小时有效期并清理过期会话及其关联练习数据；关闭通知仅可作为辅助，不作为失效／清理的唯一机制。账号数据不受游客清理影响。
- 游客入口固定提示：「游客进度仅在当前标签页内保留，关闭后不会保留。登录可保存并继续学习。」英文：「Guest progress stays in this tab and is not kept after you close it. Sign in to save it for another visit.」
- 游客在体验中注册，承接本次进度；登录已有账号时合并当前游客尝试，保留历史成功和练习记录，不覆盖已完成站点。合并只接受当前持有凭据的游客记录，合并后撤销旧凭据，重复提交不得复制记录。
- 旧匿名数据不自动删除或重置。当前浏览器持有旧凭据时，提供明确的保留入口，使用户能将旧进度关联到新账号；旧内容版本仍按原兼容流程处理，不能伪装成新版课程。
- 不同课程版本或冲突请求不能直接混合，返回明确错误并保留两边记录；旧版可在欢迎页单独勾选后关联新账号，再按原兼容入口升级。服务器访问凭据最长有效 24 小时，实际数据删除由后续 API 访问或清理命令执行，不承诺无访问时准点物理删除。

## 4. About 与相关措辞

原「Pick up where you left off / 下次接着逛」改为「Save your journey / 留住这段漫游」。

- 未登录／游客：说明本次体验可继续，登录后才能为下次保存；提供登录入口。
- 已登录：说明进度已保存到账号，下次登录可接着练习。
- 同步检查其他「自动保存／回来继续」表述，避免向游客承诺永久保存。任务中的当前步骤保存和账号的长期保存要保持准确。

## 5. 工程边界与验收

保持原 FastAPI、SQLite 与前端工程；新增账号、登录凭据和临时会话数据结构，迁移兼容已有数据库，不改写用户的现有开发数据作测试。账号认证与学习会话关联，所有既有任务与语音接口仍核对会话所有权。

检查用户名规范化／并发唯一、密码哈希、错误登录、限流、会话过期与退出、游客刷新／新标签重新入口、账号再次登录恢复、游客转账号合并及重复／跨账号访问隔离。检查没有凭据时不会自动创建长期匿名进度，旧匿名记录仍有显式保存路径。

前端覆盖欢迎表单、错误／等待、游客入口、账号入口／退出、About 文案、中英及 1440 / 390 / 320 px、导航顺序、登录后默认 About、刷新深链接与录音离开保护；使用隔离测试数据库实际走登录与游客流程。更新接口说明、运行说明、验收、进度后按项目约定提交推送。

不调用真实语音服务，不读取／展示真实用户密码，不新增付费服务或部署。具体安全实现依据 [OWASP 认证建议](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html) 与 [密码存储建议](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)；浏览器生命周期边界见 [MDN sessionStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/sessionStorage)。

## 6. 实现与验收交接

已按先文档后代码顺序完成本轮。账号会话为 30 天，密码采用带随机盐的 scrypt；游客凭据仅在标签页保存。业务请求绑定页面当前会话，防止跨标签账号变化误写；登录时隔离旧请求，失败保留游客体验。历史识别与旧版未完成回合超过 30 秒可安全终结，不自动推进任务，避免永久阻塞导入。实际接口和维护方式见 [API 说明](../backend/API.md)，测试、浏览器画面与未覆盖范围见 [修改 3 验收](Batch-2-revision-3-acceptance.md)。
