# 批次 A 修订 3：引导练习、识别反馈与手动继续

确认日期：2026-10-17。用户称“批次 A 修改 3”，沿用仓库文件命名为“修订 3”。先保存本文，再实施代码。本文件覆盖修订 2 的自由追问与识别后自动切题；未覆盖的注音、慢速、地图与完成后 Review 约定继续有效。

## 1. 练习定位与步骤

南翔采用明确目标的逐题场景练习：商品 → 数量 → 堂吃或外带 → 最终订单核对。每题先选择想练的表达，再看汉字、注音、释义并试听、Speak。数量统一按份；保留 1–20 份有效范围和一/二/三份便捷选项。预选只确定本题目标，不立即提交订单。

用户进一步明确：**取消所有临时追问，只保留已经设计好的对话问题。** 当前主流程固定为 NX-N01 商品、NX-N02 数量、NX-N03 方式、NX-N09 订单核对，完成后 NX-N10 收尾。取消“侬讲个是只，还是份？”以及商品不支持、数量越界、含糊修改等分支追问。没有听懂、数量冲突或表达不符时保留本题，反馈放在结果卡中，不让店员开启额外自由对话。编辑只返回对应的既定题，不产生新题；不增加逐字发音评分。

## 2. 说完后必须展示结果

主动停止录音 → 自动 ASR → 自动核对本题表达 → 展示结果卡并停留。保留停止录音按钮，不添加静音停止，不自动打开麦克风。

结果卡同时显示本题目标、识别原文和明确结果：

- 正确：识别结果符合本题目标。提供“下一步”，最后核对题提供“确认并完成”。
- 不正确：识别结果与目标冲突或无法理解，解释简短具体，例如“本题练习两份，识别到了七份”。提供“再说一次”及“用所选答案继续”。后者是用户显式使用选择辅助，不算语音正确。
- 未识别到语音：明确显示未获得转写，不伪造原文；可重试或使用所选答案继续。
- 服务/设备故障：显示“暂时无法判定”和原因，允许选择继续，不称为发音错误。

只要返回了识别文字，不论核对是否成功，都应可见，不藏在“上一条回应”折叠项里。原始转写保持不变；同音容错仅用于本题核对，不改写用户看到的识别结果。正确与否只表示是否符合本题表达，不能声称声调、每字发音或语言掌握已通过。

## 3. 明确点击才前进

成功结果停留等待用户点击，不自动切问题、播放下一句或提前展示完成。评估结果持久保存；刷新、离开再返回后仍应看到待确认的结果，不能以恢复为由跳过反馈。

点击“下一步”才将正确回答应用到订单并进入下一题。未通过时也能由用户点击“用所选答案继续”推进，按选择辅助记录；不自动把误识别的数量写进订单，也不把预选答案冒充原话。未通过后无需被迫反复录音。需要更换答案时先选择新的练习目标，再练习或用已开放的 Choose 回退。

最后一题仍显示真实订单摘要。说出确认后的评估结果也要停留，由用户明确点击“确认并完成”且保存成功才完成；失败后的选择确认同样需要明确操作。没有完成就不开放 Review。

## 4. 核对与回退规则

- 数量题的上下文已定义为份，允许“两份”“我要两份”“两”等合理省略；“两分”等有限、明确的同音误写可在该题中识别为同一个目标。
- 选两份却识别成七份，不通过本题，也不修改订单为七份；否定、相反用餐方式、多个冲突数量不被自动视为正确。
- 核对只验证当前步骤，不从一句自由表达跳过多个题目；修改数量/方式时将当前练习目标明确传给后端，不沿用旧确认问题的上下文。
- 语音失败后的回退资格与当前问题一起保存，重新打开页面或退出修改不丢失。下一道新题重新要求先 Speak。服务/设备不可用仍可直接回退。
- 请求幂等、保存失败恢复、取消与迟到隔离继续保留。旧评估不能应用到新题或已改变的目标；重复点击不能重复计步或完成。
- 历史 R1/R2 会话与内容保留版本，新流程独立绑定；不静默更改历史订单来源，不自动重置用户会话。
