## 2. 视觉方向与边界

当前方向是现代旅行手册与江南园林版画：纸面米白、深青绿、少量赭红，配原创园林、池塘、曲桥和木柜台。地图中的地标帮助识别四个学习地点，门店和角色属于教学情境，不声称复刻现实室内、人员或当天菜单，也不提供实地导航。

正式应用没有直接复用 `References/prototype-app.html` 或 `References/spec-interactive.html` 的页面与模拟能力。历史材料仍是 progress update，本次画面由 React、CSS 和可编辑 SVG 重新组织。

地图使用一张共享园林，推荐顺序仍为老饭店 → 梨膏糖 → 南翔 → 湖心亭。当前批次只接入南翔交流，其他三个地点可选中查看元数据并明确标示制作中；这不是任务通关解锁规则。后续站点就绪后仍须允许直接进入。

## 3. 当前设计系统

### 3.1 色彩与组件

下表来自当前 CSS。正式视觉验收仍需检查真实文本/背景组合的对比度，不能仅凭色值表认定达标。

| Token / 值 | 当前用途 |
| --- | --- |
| `--ink: #292f2a` | 主要文字 |
| `--green: #214f46` | 主按钮、选中地点、导航与重点信息 |
| `--green-light: #e9eee6` | 辅助浅底、轻量悬停状态 |
| `--red: #a04d3b` | 焦点轮廓、少量提示与装饰 |
| `--muted: #6b7168` | 次要说明 |
| `--line: #dedfd5` | 分隔线、卡片边缘 |
| `--cream: #f4eee3` | 纸面与场景暖底 |
| `--white: #fffefb` | 阅读卡和操作区实色底 |
| 页面底 `#f9f7f1` | 全局背景 |
| 竹色 `#d9bd8d` | 状态册色板与暖色素材参考；当前不是独立 CSS 变量 |
| `--radius: 16px` | 地图等主要容器；按钮 8px、其他卡片约 13–17px |

主/次按钮桌面 `min-height: 48px`，配文字和方向图标。全局按钮基线为 44px；次级控件已统一补足触控高度；390/320px 英文地图、南翔检查到的可见按钮高度均不少于 44px。仍需实体触屏检查。选中不能只靠颜色：地点使用编号/勾选、回应选项使用选中样式和相应状态，完成章有明确文字。

常用间距为 8、12、16、20、24、32px，页面桌面左右 64px，中等视口 32px，手机 20px，360px 以下 14px；这些值当前写在组件样式中，尚未全部抽成独立 spacing token。

### 3.2 字体与许可记录

正文声明 `Inter, -apple-system, BlinkMacSystemFont, Segoe UI, PingFang SC, Hiragino Sans GB, Microsoft YaHei, sans-serif`；标题声明 `Georgia, Songti SC, STSong, Noto Serif CJK SC, serif`。当前仓库没有随应用分发这些字体文件，也没有 `@font-face` 或外部字体下载；浏览器使用设备已有字体或回退字体。因此不同系统的字宽和行高仍须实测，CSS 中写出某字体名称不表示该字体已打包或获得再分发许可。

后续若嵌入字体文件，需另记录实际文件、来源、版本和相应许可；本批次不能把字体栈写成已经交付的跨平台统一字库。SVG 原创美术不含嵌入字体；招牌、任务和按钮的可读文字由 HTML 另排。

图标来自已安装的 `lucide-react`，其包内 `LICENSE` 声明 ISC，并对从 Feather 衍生的列名图标保留 MIT 告知。后续分发应随依赖保留相应许可告知。原创 SVG 的来源和再分发边界记录在 [资产清单](Asset-manifest.json)，本稿不另授予仓库尚未声明的整体许可证。

### 3.3 字号与实际限制

当前根字号 16px、行高 1.6；桌面主标题约 36px，英文主标题约 38px，手机主标题约 27–33px；表达核心汉字 27px。主要操作与正文按层级采用约 14–16px，部分辅助标签更小。次要文字颜色已加深以提高阅读清晰度。

共同规范的验收目标仍为正文约 16–18px、核心汉字约 24–28px、**审核后的真实拉丁注音至少约 16px**。目前表达卡里的小字是「待审核」标签，不是可读的最终拉丁注音。其字号不能直接沿用到正式注音。最窄 320px 英文页面已检查横向溢出和可见操作高度；200% 缩放、实体设备字宽与全部文本对比度检查仍待执行，不能把可见布局检查当成完整无障碍认证。

## 4. 地图和南翔的响应式组成

| 视口目标 | 地图 | 南翔 | 需要实际核验 |
| --- | --- | --- | --- |
| 桌面 1440×900，中/英 | 地图与 326px 地点详情卡并列，下方四站文字列表 | 场景与约 304px 订单卡并列，下方当前对话与三种回应入口 | 长地名、地图标记遮挡、订单与操作的视线顺序 |
| 手机 390×844，中/英 | 地图在上、地点卡在下；地点卡内部建筑与正文分列；路线列表两列 | 居中近景裁切；订单在场景下方，收集状态默认折叠为摘要、核对和完成时展开；输入和帮助改为纵向流 | 长英文换行、键盘打开、帮助/核对、手指点击区域 |
| 最窄 320px 与横屏 | 仍提供完整文字地点列表 | 主要信息纵向滚动，不依赖图片热点才能继续 | 320px 英文已测无横向溢出；横屏、实体设备待测 |
| 200% 缩放 | 保留地点名称与进入按钮 | 当前问题、错误和提交可达 | 不能因为放大丢失操作或迫使读取裁掉的文字 |

实际样式断点为宽屏 `min-width:1550px`，以及 `max-width:1190/900/680/360px`。900px 以下南翔的场景/订单改为单列，680px 以下地图/详情也改为单列，导航换行到独立一排。没有另外一套复制的手机应用。

手机南翔当前使用居中 SVG 裁切，并保留独立「认识一份小笼包」「怎么说外带」文字按钮。文本框获得焦点时通过 CSS 压缩场景并保持流式滚动；没有依赖 `visualViewport` 的专项适配。实际设备软键盘下当前问题和提交是否可达仍需验证，不能从桌面视口模拟推定通过。

## 5. 图层、裁切与数量表达

| 资产 | 坐标与图层 | 交付与裁切规则 |
| --- | --- | --- |
| `GardenMap` | `viewBox 0 0 1100 690`；园墙、水面、路径、后景植物、四地标、前景植物 | 内容安全区 `(120,100,860,485)`；SVG 采用 `meet`，外层布局可能裁边。四地标和四个独立操作入口均须可识别，手机不能只留无法点到的建筑 |
| `Landmark` | `viewBox -145 -225 290 255`；四种门面小图 | 安全区 `(-130,-217,260,245)`；地图详情和路线回顾复用。真实名称由外层 HTML 提供 |
| `NanxiangScene` | `viewBox 0 0 1100 580`；窗格、灯光、后柜、原创店员、前柜、蒸笼和袋子、蒸汽 | 安全区 `(260,84,640,370)`，手机焦点约 `(570,265)`；SVG `slice`，手机居中近景。店员脸、核心蒸笼和必要操作不能被裁掉 |

每个 SVG 都有 `role="img"`、当前语言替代文本和独立 `useId` 标题。建筑、人物和物件是图层；任务、数量、订单、字幕、按钮都保持可编辑文字，不烘焙进图片。

`welcome/listening/checking/packed` 是四个呈现参数，但不是四套完整独立动作帧：欢迎与倾听共用举手轮廓，核对与打包使用柜台手势，`packed` 关闭一个前景蒸笼。它们不能证明打包装袋动画完成，也不能自行修改订单或保存进度。

场景蒸笼是环境道具，不显示用户已订数量；订单以已保存字段和明确份数为准。单位帮助示意两个份量单元，并说明「一笼示意对应一份，两份不等于两只」。素材中包子的装饰数量不代表真实门店装数。

## 6. 交互、关键状态和服务边界

| 状态/动作 | 当前设计与代码行为 | 验证边界 |
| --- | --- | --- |
| 地图进入南翔 | 无既有尝试时先展示到店任务，开始后创建尝试；继续已有尝试 | 点击地图卡不预填两份外带，不自动录音 |
| 柜台初始状态 | 商品、数量、方式都未知；订单显示已保存信息 | 目标卡不是订单 |
| 三种回应 | 说话、文字、选择从开始均可使用；选择先留在草稿 | 选中、帮助和填入不等于提交 |
| 单位/外带热点 | 打开单位说明或表达卡；单位展示记录独立事件 | 不凭点击蒸笼/袋子更新订单 |
| 核对 | 只有规则返回有效摘要才显示；保留文字/选择/语音入口 | 确认绑定摘要版本；修改使旧确认失效 |
| 处理中 | 处理提示和取消入口，保留草稿 | 转圈不是模型已成功或订单已保存 |
| 完成 | 根据服务端完成状态显示回顾、完成章和重练入口 | 保存失败不能显示完成；角色姿势不是完成依据 |
| 返回/稍后再做/重练 | 返回保留已提交进度；跳过单独提交；重练创建新尝试 | 不覆盖过去的成功记录 |
| 语音 | 主动开始、停止后本地回听、明确提交识别、转写核对后提交回应 | 未配置 ASR 时说明服务待连接，仍可本地录音/回听或用其他通道 |
| 错误 | 全局错误提示、相关重试/取消；麦克风错误有文字/选择替代 | 浏览器权限、网络中断和真实服务结果仍需实测 |

`#design` 包含输入、等待、恢复、核对、保存、学习支持六张状态示例，可用来集中讨论视觉层级。它们不模拟服务调用，不写入订单完成，也不能代替真实流程验收。当前真实业务仅覆盖南翔开发链路；老饭店、糖店、茶楼的独立流程属于后续批次。

## 7. 焦点、键盘和减少动态

源码已有跳到主内容链接、带文字名称的按钮、选中状态、输入 label、当前问题 `aria-live="polite"` 和原生 `<dialog>.showModal()`。弹窗保存打开前的焦点，关闭时尝试返回；Esc 使用原生 cancel 事件关闭。地图另有可键盘操作的四站列表，必要动作不要求拖拽或悬停。

键盘验收需实际确认：Tab/Shift+Tab 不进入弹窗外，关闭回到合理触发点；语言/设置/表达卡开合不丢焦点；输入标签页可理解且可操作；页面切换后焦点顺序合理；录音权限弹窗返回后有明确下一步。页面导航已滚到顶部并将焦点移到主内容，输入标签页支持左右箭头、Home/End 与单一 Tab 停靠点。屏幕阅读器完整检查仍待执行。

交互过渡约 160ms；处理中 spinner 为 1s 循环。当前没有强制相机转场、实时口型或长打包动画。系统 `prefers-reduced-motion:reduce` 和会话「减少动态」设置都关闭动画/过渡并改为即时滚动；静态状态文字和完成结果保持可见。录音开始停止应用媒体，应用媒体采用排他播放；环境音当前未实现，也没有默认开启。

## 8. 候选内容和后续设计门槛

开发卡保留 E08「我要 / 两份 / 小笼包」、E09「打包 / 带走」、E05「对个」候选及释义，并显示待审核。拉丁注音、中文近似读音与示范音频尚无真实值；对应播放禁用并说明原因，不能用假读音或普通话音频填补。

英文模式保留核心汉字和英文释义，没有中文近似读音入口；中文模式的入口默认收起，展示近似性质与待审核说明。填入回应使用当前语言的语义文字，仍需用户提交；不能记录成已学习或说出了上海话。

审核文本到位后必须用真实长短词组和常/慢速音频复核四组布局，再讨论正式设计批准。南翔完整交付还需准确的两份装袋/递袋反馈、实体设备录音到回应的端到端检查、内容与 UI 的最终验证。真实服务已用合成英文诊断连通，详见语音记录；这不构成上海话教材质量验收。批次 A 的当前设计初稿不提前承诺这些已完成。
